# OffSec UGC — What changed (key updates, 2026)

The most important shifts a returning author must know:

1. **Standalone offensive VM labs are PAUSED (from 2026-08-10).**
   Only accepted now: Chained-Host Offensive, Grimoire, all VM-based Defensive,
   and CVE (Defensive-only) labs. → A single "root me" box is no longer accepted;
   go multi-host or defensive.

2. **AI-R (AI-Resistant) is MANDATORY (v6, 2026-08-03).**
   Inflate volume + realistic breadth (50–80+ pages, thousands–100k+ DB rows,
   ~200 groups / ~2000 AD users) so automated AI solvers burn tokens; human
   difficulty unchanged.

3. **Hard limits on AI use (v3–v4).**
   AI must NOT write the walkthrough, generate secrets/passwords/tokens, or
   fabricate artifacts (artifacts must come from a live, working lab). Permitted:
   build scripts, test-data population, early ideation. Penalty ladder: warning →
   6-month suspension → permanent ban.

4. **Grimoire structure tightened.**
   ≥8 questions (v5), no leading/yes-no questions, ≥2 distinct artifact types
   (v3), points by difficulty (Easy 40 / Med 60 / Hard 80 / Insane 100),
   password-protected artifact zip (`WordWordWord123`), PCAP >20 min with
   background noise, consistent timestamps, no own name/handle as usernames.

5. **Payment/priority.**
   Advanced (chained) up to $1,500; wishlist match = review ≤3 days + 25% uplift;
   Grimoire paid on the next weekly cycle once accepted.
